# 球队页一键清除小组筛选

**功能目录**：002-clear-team-group-filter  
**创建日期**：2026-11-05  
**状态**：草稿，规格质量检查通过

## 项目规格评审摘要

用户在查看部分小组后，可一次操作回到完整球队列表。范围限于球队页已有分组筛选旁的清除入口、选择重置、焦点和双语。保留现有小组多选和“全部小组”操作。不新增数据、页面或偏好设置。无阻塞规格的待确认项。主要风险是按钮消失时焦点丢失，以及窄屏触控误触。

## 用户场景与验收

### US1 一次清除已选小组

- **FR-001 按状态显示**。默认显示全部球队，清除按钮不可见且不可通过键盘聚焦。选择任一小组后，筛选入口旁出现“清除筛选”，英文为“Clear filters”。手动取消最后一个小组或选回“全部小组”后，按钮消失。验收覆盖单选、多选和未筛选三种状态。
- **FR-002 恢复列表与选项**。选中一个或多个小组后，激活清除按钮一次，恢复显示当前可用的全部球队，取消所有具体小组的勾选，并将筛选状态恢复为“全部小组”。重新打开筛选面板核对结果，再选择一个小组时只显示新选小组。
- **FR-003 键盘与语言**。在中英文界面分别通过 Tab 到达按钮，并分别用 Enter 和空格验证清除。操作后按钮消失，焦点回到筛选入口，焦点位置可见。每种语言的按钮名称与当前界面语言一致。

## UI 功能：需求与设计基线

**UI，轻量模式**。设计来源为本次文字需求与现有球队页，关联 FR-001 至 FR-003。清除按钮拟放在筛选入口旁，面板收起时仍可操作。窄屏下按钮应完整可见，无重叠，点击不误触相邻控件。沿用当前主题及控件视觉。无外部设计稿，布局细节在规划中核对。按钮状态由已有选择决定，沿用球队列表的加载、空数据与错误表现，无可选小组时不出现清除按钮。

## 成功标准

- **SC-001** 单选和多选场景均可通过一次清除恢复完整列表，原有具体小组勾选残留为零。
- **SC-002** 中英文界面各通过 Enter 和空格清除场景，四次操作均恢复筛选入口焦点。
- **SC-003 实体手机发布验收**。QA 使用至少一台实体手机，在本次待发布版本上选中两个小组并收起面板。在正常页面缩放下，确认按钮完整可见、一次点中且不误触相邻控件，列表恢复到筛选前的全部球队。重开筛选确认具体小组均未勾选，“全部小组”已选。QA 在后续任务的验收记录中填写设备型号、浏览器及版本、测试版本、执行人、日期和实际结果。**真机未执行或未通过时阻塞发布**。桌面模拟视口和自动化结果可用于开发验证。
