# 积分榜展示数据模型

| 对象 | 字段和归属 | 规则 |
| --- | --- | --- |
| 小组 | 组标识 A 至 L、进入页面时的球队序列、一个排序状态 | 每张卡片只处理本组球队行。沿用视图现有的空组省略行为。 |
| 球队积分记录 | `code`、`name`、`position`、`points`、`goalsFor`、`goalsAgainst`、`goalDifference` 及其他现有统计 | 整行移动，保留球队链接、名次、资格样式和统计。排序只读取四个指定字段。 |
| 行的初始序号 | 组内从零开始的索引 | 按视图输入顺序确定，整个页面交互期间固定。不同球队的序号在组内唯一。 |
| 小组排序状态 | 初始为空；选中时包含指标和方向 `ascending` 或 `descending` | 仅存在于本次页面使用期间。新建卡片按输入顺序开始。 |

## 状态转换

| 操作前 | 选择 | 操作后 |
| --- | --- | --- |
| 未选择或当前为其他指标 | `goalsAgainst` | 该组按失球数升序 |
| 未选择或当前为其他指标 | `points`、`goalsFor`、`goalDifference` 之一 | 该组按所选指标降序 |
| 当前指标已生效 | 再次选择同一指标 | 翻转当前方向 |

## 数值和顺序约束

以 `Number.isFinite` 校验原始统计值。零、负数和多位数均参与数值比较。缺失字段、`null`、字符串以及非有限数值归入无效值。展示格式（例如正净胜球的 `+`）不参与比较。读回 DOM 中由视图写入的有效数值时，先区分属性缺失与值为 `0`。

排序依次比较有效性、有效数值、初始序号。有效记录始终在前，只对有效数值应用方向。并列或同为无效时按初始序号升序。由初始序列派生展示顺序，保留所有行，源数组和记录只读。全组同值或仅一行时仍更新所选指标及方向。
