# 小组积分榜排序交互契约

每张已展示的小组积分表提供四个排序按钮，沿用当前界面语言的指标名称。字段与初始序号见[数据模型](../data-model.md)。

| 操作或环境 | 可观察结果 | 验收项 |
| --- | --- | --- |
| 首次进入页面 | 每组的分数、进球数、失球数和净胜球数表头各有一个 `type="button"` 的原生按钮。球队按输入顺序展示，各列均无生效方向。 | AC1、AC10 |
| 指针点击排序按钮 | 每次点击触发一次排序。首次选择和切换指标时，失球数升序，其余三项降序。再次选择当前指标时翻转方向。仅本组活动表头具有 `aria-sort="ascending"` 或 `aria-sort="descending"`，按钮旁的 ↑ 或 ↓ 与行序同步。 | AC2、AC3、AC11 |
| 分别使用 Enter 键和空格键 | 两个独立用例分别从该组未排序的页面开始。用 Tab 聚焦“分数”按钮，用本用例对应的键连续激活两次。第一次按键后为分数降序、`descending`、↓，第二次为升序、`ascending`、↑。每次按键都核对恰好触发一次排序、焦点仍在同一按钮、活动表头唯一，且完整球队行序与预期一致。 | AC2、AC3、AC11 |
| 翻转某列，改选其他列，再切回 | 切回时采用该列的默认方向。 | AC4 |
| 操作含多位数、负数、真实零、并列和多个无效值的小组 | 按数值排序。两个方向均以初始序号消解并列。无效统计显示 `—` 并提供与界面语言一致的缺失说明，对应球队始终置于有效值之后并保持彼此初始顺序。 | AC5、AC6、AC7 |
| 空组、单队或全组同值 | 空组沿用既有省略行为，其他组可正常浏览。已展示的组即使行序相同，也随选择更新方向提示。 | AC8 |
| 先让 A 组按分数降序、B 组按失球数升序，再切换 A 组指标并翻转方向 | 每次仅更新 A 组。对照操作前的 B 组，球队、统计、行序、活动表头及方向提示逐项相同。 | AC9 |
| 排序后查看名次、数据说明并进入球队详情 | `position`、资格样式及 `data-route` 随原行保留，详情链接仍指向同一球队。用户仍能识别静态演示快照的性质，方向提示只描述浏览顺序。 | AC10、AC12 |
| AI 未配置，或 AI 服务返回错误 | 在两种环境中分别从站点导航进入积分榜，均可浏览完整球队记录，逐项操作四列并得到对应行序和方向。排序期间新增 AI 请求数为零。 | AC13 |

浏览器验收从真实页面入口触发按钮。中文和英文界面复用现有指标译名并表达相同的排序方向。
