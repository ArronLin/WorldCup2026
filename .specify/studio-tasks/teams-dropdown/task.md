# 球队下拉筛选

目标与边界：在球队列表页使用原生下拉框筛选球队，沿用小组卡片和详情链接；不增加路由、存储或数据接口。

## 验收

- AC1：带可见标签的下拉框包含“全部球队”和所有球队名称，默认显示全部。
- AC2：选择球队仅显示该球队及所属小组；选择全部恢复列表。
- AC3：中文与英文选项一致，支持键盘与窄屏；重复初始化、释放和重渲染不重复处理事件。
