# Bug Assessment: 球队页应按小组即时筛选并支持外部点击关闭

- **Slug**: teams-group-filter
- **Created**: 2026-10-26
- **Source**: pasted text
- **Verdict**: valid
- **Severity**: low

## Report (verbatim or summarized)

> 当前球队页面的筛选，应该是小组筛选而不是球队筛选；在下拉列表里选择小组后，需要可以即时在球队页面里反映；且在下拉列表外任意位置点击后，就退出下拉列表

任务标识经用户明确确认为 teams-group-filter。本轮仅评估，不实施修复、不登记或推进工作流任务、不运行测试。

## Symptom

球队页下拉列表提供具体球队，按球队代码过滤，无法选择小组并显示该组完整球队；展开的 details 没有列表外点击关闭逻辑。期望改为小组筛选，选择立即更新页面，点击筛选控件外部关闭面板且保留选择。

当前球队选择的 change 处理本身是同步的；未发现“已有球队选择必须确认或刷新才生效”的代码证据。本报告将即时更新作为小组筛选的验收要求，不将未复现的延迟另判为缺陷。筛选维度是本轮明确修正的需求，不能据此声称上一轮存在已证明的历史回归。

## Reproduction

基于当前源码的可复现步骤；本轮未执行浏览器复现：

1. 打开 #/teams，展开“筛选球队”。当前可见选项是“全部球队”和具体球队，无法选择“小组 A”。
2. 勾选一支球队：控制器立即隐藏其他球队，所属小组仅剩该球队，而非展示完整小组。
3. 保持下拉面板展开，点击页面标题或 app 外部的页脚空白等不触发导航/重渲染的位置：筛选控制器没有关闭逻辑，details 不会由该控制器移除 open。
4. 标题、导航等触发重渲染的操作可能间接替换面板，不能以此代替“任意外部点击关闭”的验证。

## Suspected Code Paths

- `src/views/teams.js:11–17`：已有 byGroup 和排序后的 groupKeys，可以直接作为小组选项来源。
- `src/views/teams.js:22–26`：复选框值为 team.code、文字为球队名称，维度与本轮需求不符。
- `src/views/teams.js:30`：data-team-group 只是无值标记；按组过滤需要提供可识别的小组值。
- `src/teams-filter.js:6–19`：读取 data-team-choice 集合，以 row.dataset.teamCode 判断显示；仅因子球队隐藏而隐藏空小组。
- `src/teams-filter.js:21–24`：仅在 app 根节点注册/移除 change，没有文档级外部点击关闭处理。
- `src/app.js:137–139`：在持久 app 根节点初始化控制器，新增监听必须纳入原有释放及去重责任。
- `public/i18n/zh.json:2–3`、`public/i18n/en.json:2–3`：现有文案为“筛选球队/全部球队”及对应英文，需要调整小组语义。
- `tests/teams-dropdown.test.js:22–67`、`e2e/teams-dropdown.spec.js`：目前断言具体球队多选，没有小组选项、完整组展示或外部点击关闭覆盖。

## Root Cause Hypothesis

置信度 **high**。视图与控制器均按球队代码建模，虽已有分组展示数据，却没有将小组作为筛选值。使用 details/summary 只提供展开/折叠，当前代码未实现外部点击关闭。问题局限于筛选展示与交互，没有数据丢失或权限风险，严重度 low。

## Proposed Remediation

**Preferred**：保留已确认的复选框多选下拉交互，将选项改为“全部小组”和当前数据中的各小组（本轮 JSON 为 A–L，每组 4 队）。复用 groupKeys，给组卡片记录小组值，按所选小组集合显示整个组及其全部球队；移除旧球队筛选残留对行可见性的影响。每次 change 立即在当前 DOM 生效，不增加确认按钮或等到关闭面板才应用。选择组时面板保持展开，便于继续多选；“全部小组”与具体组互斥，取消最后一个组恢复全部，延续现有空选语义。

在控制器内注册文档级 click 监听（建议捕获阶段，避免被外部元素停止冒泡阻断），只关闭当前 root 内已展开且不包含点击目标的筛选面板。覆盖 app 内外的点击，而非仅在 app 根节点监听。点击面板内部标签、复选框及空白不得误关；summary 继续遵循原生切换。关闭不清除选择，不调用 preventDefault/stopPropagation，不抢走外部按钮焦点，不阻止导航、语言/主题切换等原本操作。与 change 监听一起由 dispose 移除，重复初始化仍返回同一控制器；每次事件查询当前 DOM，避免重渲染后使用旧引用。

**Files likely to change**：

- `src/views/teams.js`：小组选项和组值标记。
- `src/teams-filter.js`：集合维度、即时组过滤、文档级外部点击及释放。
- `public/i18n/zh.json`、`public/i18n/en.json`：筛选小组/全部小组文案，复用 common.group 显示组名。
- `tests/teams-dropdown.test.js`：更新为小组场景并验证监听生命周期。
- `e2e/teams-dropdown.spec.js`：实际浏览器验证即时更新、内外点击、双语、键盘和窄屏。
- `src/styles/pages.css`：仅在验证发现面板覆盖结果、窄屏越界或焦点可见性问题时局部调整。

**Tests to add or update**：

- AC1：默认全部小组；列表提供各组而非球队名称，不硬编码数据数量；当前快照应为全部项加 12 个小组。
- AC2：勾选 A 组，在下拉仍展开时立即只显示 A 组完整 4 队；追加 B 组立即显示两组共 8 队；不需要确认、刷新或关闭。
- AC3：取消一组只隐藏该组；取消最后一组及选择全部恢复所有组/球队；关闭、重新展开不重置选择。
- AC4：点击 app 内部标题/空白、app 外部页脚/空白均关闭面板；点击面板内部不关闭；summary 仍可折叠；关闭不阻断被点击的按钮或详情链接。
- AC5：重复初始化一次操作仅处理一次；dispose 后 change 和文档 click 均失效；释放后重建和页面重渲染后都正常，旧面板没有残留行为。
- AC6：中文/英文小组标签一致；键盘展开/勾选、焦点提示、窄屏操作可用；离开球队页后外部监听不影响其他页面。
