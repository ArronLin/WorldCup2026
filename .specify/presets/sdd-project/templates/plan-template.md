### 最短验证路径与原生产物分工

- research.md：摘要列决定、备选、理由及关键来源，不粘贴背景或检索日志。
- data-model.md：只写本功能实体、约束、状态和迁移；静态 JSON、本地存储与共享归一化仅在受影响时展开。
- contracts/：只写接口、兼容与错误语义；涉及 AI 流时按需说明 HTTP／SSE、取消、超时和降级，不复制实现。
- quickstart.md：给出最短命令路径、前置条件、目标页面、预期结果和对应排障。候选入口为 npm run dev、npm run build、npm run preview、npm test、npm run test:e2e 和 npm run validate:data，按变更选择。/?mock 仅验证模拟界面；Function 集成核实 npx netlify-cli dev 及所需环境，不把前端服务当作 Function 环境。

本地自动验证与必要人工交接分开说明。仅在项目约定或明确需求要求时安排人工项；当前机器缺设备、数据或权限但可在其他环境自动运行的测试仍属自动化测试并记录阻塞。来源、技术详情和未核实命令置于文末；未知命令写“待核实”，不新增 CI 接入任务。
