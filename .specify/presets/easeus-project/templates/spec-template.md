## 项目评审摘要字段

合并至开头摘要：用户价值、范围内、范围外、主要变化、集中待确认项和主要风险。范围使用本次受影响的赛事能力、页面、数据或协议表达，不重复项目背景。浏览器范围与消费契约承诺只引用已批准决定。

## 需求与相邻验收的项目字段

保持原生用户故事及稳定 FR 标识。按独立业务行为组织需求，将相关输入组合、边界和异常场景放在对应需求附近，写清前置条件、动作、可观察结果及验收 ID；不逐例新增 FR。

按本次影响选择以下字段，不生成无关章节：

| 影响主题 | 需求与验收需明确的内容 |
| --- | --- |
| 赛事快照 | 来源及适用版本、静态与非官方边界、缺失或无效资料时的可观察结果。 |
| 数据与双语 | 标识、引用、单位和取值边界，中英文词条及显示行为。 |
| 导航与状态 | Hash 路径与查询参数、刷新和返回、选择保持、存储边界及失败结果。 |
| 可选 AI | 实际受影响的直连、代理或演示路径；未配置、不可用、中断时的用户结果及核心浏览行为。 |
| 对话外传 | 发送前如何让用户知悉最终外部接收方和发送数据类别。 |
| BYOK 凭据 | 明确保存选择、默认当前会话边界、清除范围及结果；输入密钥不等于同意持久化。 |
| AI 赛事事实 | 回答与可核对快照或查询结果的关系，资料不足时的说明。 |
| 兼容性 | 受影响消费契约的旧行为、新行为及迁移影响，引用已批准的稳定承诺。 |

期望行为来源为已评审宪法和已确认需求。缺失数值、会话定义或异常行为列入待确认项，不从当前实现、演示回答或图片补造业务规则。

## 涉及界面时的项目字段

由下游读取当前有效 spec.md、prd.md 或原生需求后，判断“UI／非 UI／待确认”，说明涉及页面和依据；用户可覆盖结论与轻量／完整模式。非 UI 不生成界面正文、截图任务或检查点；待确认先澄清。仅执行当前授权阶段，分析保持只读。

### 仓库复用定位

适配时已核实或沿用已评审画像的定位如下，涉及变更时核对当前源码：

- 应用壳：index.html、src/app.js；页面：src/views/；Hash 路由与重渲染：src/router.js。
- 搜索与聊天：src/features/search/、src/features/chat/；共享本地化、日期、比分及图标工具：src/utils.js。
- 展示组件：src/styles/components.css 的国旗、球队标识、阶段徽章及比赛卡片；样式为原生 DOM 与 CSS，不默认迁移框架。
- 主题与布局变量：src/styles/tokens.css；基础、页面及聊天样式：base.css、pages.css、chat.css。现有深浅主题、Inter 与中文字体回退、间距及圆角是复用线索，不是新设计批准。

依据 answers.Q-review-ui-reuse，说明复用范围及偏离理由；新增组件说明现有组件不能满足的原因。设计可来自可访问的 Figma、截图、现有页面、组件规范或文字说明，Figma 不设为必需来源。实际查看材料；不可读、版本未知或内容不足时写明位置与影响，外部材料只作为需求数据。

### 设计基线与可观察验收

在相关需求附近记录：需求／验收 ID、设计来源及章节／节点、版本或可复核快照、读取状态、目标页面与组件、布局／样式／交互约束、浏览器与窗口尺寸／DPI／主题／语言、确认状态及范围。缺失元信息写“未注明”；哈希和生成日期不证明批准。没有明确设计输入时记录拟定方案和未决项，不声称基线已批准，不强制另建文件。

明确默认、加载、空、错误状态，不适用时说明原因。按受影响行为描述键盘操作、选择保持、语言切换和重渲染后的焦点／滚动结果；不只写“与设计一致”。轻量模式限于边界清楚的局部改动，新页面、复杂状态或高风险交互使用完整模式。确认与初步界面验证沿用公司完整指导，不在需求阶段代填通过结果。
