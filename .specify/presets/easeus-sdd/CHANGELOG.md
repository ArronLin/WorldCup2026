# 版本记录

## 2.1.0 — 2026-10-27

- Constitution、规格、计划及派生文档、检查清单、分析结果、任务和轻量流程统一采用评审优先结构。
- OpenSpec 的 proposal、spec、design、tasks 和自定义产物同步采用摘要先行、需确认项集中、细节后置。
- 保持 Spec Kit 按用户故事组织，在故事内依次区分测试、实施和验证任务。
- 为任务增加 `[测试]`、`[实现]`、`[验证]`、`[准备]`、`[文档]` 类型标签，便于测试与开发分别评审。
- 简体中文规则覆盖标题、小标题、表头、任务类别和状态说明；命令、路径、代码标识符和框架固定标记保持原样。
- 默认覆盖率规则按可靠采集能力确定适用范围，不用性能分析事件冒充覆盖率。

## 1.0.0 — 2026-10-15

- 9个核心阶段 wrap、5个模板 append，不复制或替换原工作流。
- Claude Code 与 Codex Desktop 双集成物化和检查。
- 项目路径、CodeGraph、OpenDeepWiki、快照及新增行基线配置。
- 中文、真实 TDD、新增生产代码单元测试行覆盖率 ≥80%。
- 有效断言、真实执行、反向验证、任务完成证据及只读边界。
- 可重复配置、受管理锚点、备份、MCP 冲突保护、卸载恢复。
- 标准库单元测试与真实 Specify CLI 隔离集成测试。
